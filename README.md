## 游戏概念
游戏名称： The Unnamed Realm｜未名之境

游戏类型： 单人 2D 探索、环境解谜、分支叙事

目标玩家： 喜欢奇幻世界、轻度解谜与自我探索的玩家

建议完整体验： 约 25–40 分钟；课程原型先完成 8–12 分钟 （待定）

玩家扮演一名没有名字、没有既定身份的旅人，进入由多个独特领域组成的奇幻世界。在探索过程中，玩家通过改变环境、分配资源、回应居民和保留记忆等互动，逐渐展现自己重视的事物。游戏将根据玩家在不同情境中的选择，生成一段有具体旅程依据的价值倾向解读，并赋予玩家一个属于这次冒险的角色称号。


**世界观与故事：**

未名之境曾经拥有一张完整的地图。后来，居民对于“世界应该怎样运行”产生了不同的理解，地图逐渐分裂为多个领域。
每个领域都拥有独特的运行规则，也保留着不同的生活方式与价值冲突。
玩家在中央的无名驿站醒来，手中只有一本空白图册。守图人告诉玩家：
“这里没有提前为你准备的名字。去看看，你愿意让什么留下，又愿意让什么改变。”

玩家穿越不同领域，将旅途中的“回响”带回驿站。回响记录关键经历，并逐步改变图册、驿站陈设与角色外观。
旅程结束时，世界会根据这些经历，为玩家提出一个名字。玩家可以接受称号，也可以重新为自己命名。

**理论参考：**

施瓦茨基本价值观理论关注的是：什么对一个人重要，以及不同目标之间如何相容或发生冲突。

以经典十价值框架作为设计参考：
| 价值方向 | 主要涉及的价值 | 关卡探索的问题 |
|---|---|---|
| 开放变化 | 自主、刺激 | 我愿意为了新的可能改变什么？ |
| 保守维持 | 安全、遵从、传统 | 什么值得保护与延续？ |
| 自我提升 | 成就、权力 | 我希望实现什么，又希望掌握多少决定权？ |
| 自我超越 | 仁爱、普世关怀 | 我愿意为谁投入资源、承担责任？ |
| 享乐 | 愉悦与感官满足 | 当下的快乐在我的选择中有多重要？ |

**世界一：生长庭园——你愿意让什么改变？**

主要张力： 开放变化与安全维持

参考机制： “视线之外”

核心能力： 注视使特定物体暂停变化；转身后，物体继续生长或老化。

关卡 1：种子的阶梯——教学
玩家面前是一株幼苗和一个高台。
- 面向幼苗时，它保持原状。
- 转身后，幼苗长成可攀爬的藤梯。
- 回头时，藤梯停止生长。
玩家学会“放开注视，可以创造道路”。这一段不计分。

关卡 2：庭园的边界——价值取舍
出口被藤蔓阻挡，旁边是居民维护多年的温室。玩家先看到两种改造方案的预览：
| 行动 | 即时回应 | 保留与付出 |
|---|---|---|
| 调整屏风，让藤蔓继续生长 | 新道路出现，温室的一部分被植物覆盖 | 获得新的生态空间，改变原有布局 |
| 固定藤蔓，修复旧升降梯 | 温室保持原状，旧通道恢复 | 保留居民熟悉的环境，需要投入修复资源 |

关卡 3：离开前的种子——再次观察
玩家获得一粒稀有种子，可以种在开放野地、交给温室照料，或带回驿站。不同选择形成不同的后续景象，用来观察玩家是否在新情境中延续此前倾向。

**世界二：共灯之城——你的光照向哪里？**

主要张力： 成就、权力与对他人的关怀

参考机制： 光影变化；第一版先做固定灯位，无需实时复杂阴影

核心能力： 搬运光源、分配能源，使道路、设施和居民活动发生变化。

关卡 1：点亮道路——教学
玩家将光核放入灯座，照亮一条通路。取出光核后，道路关闭，光核可以改用于另一设施。

关卡 2：最后三枚光核——价值取舍
城市正在恢复供电。玩家拥有三枚光核，所有设施的需求与效果提前可见：
- 个人试炼塔： 消耗两枚，开启可展示玩家能力的挑战与专属徽记。
- 公共升降机： 消耗两枚，让多名居民恢复出行。
- 街角工坊： 消耗一枚，开放制作功能。
- 休憩花园： 消耗一枚，形成可停留、欣赏的空间。
主线出口不依赖某一种分配，避免“为了通关只能帮助别人”。玩家可以预览与调整，离开区域时才确认最终安排。

关卡 3：谁来决定——补充观察
居民邀请玩家处理灯塔未来的使用权。玩家通过操作控制台，把权限留给自己、交给维护者，或开放为共享控制。
这一段补充观察“掌握决定权”的取向，避免将追求成就与控制他人混为一谈。

**世界三：折页档案馆——什么值得带向未来？**

主要张力： 传统、安全与自主改变

参考机制： “折叠世界”＋“遗忘之地”

核心能力： 用有限的地图槽位固定建筑，并在预设折线处连接区域。

这里的“记忆”指游戏中的地图记录，不要求玩家记住密码或大量信息。

关卡 1：折起远方——教学
玩家拖动一条折线，让两个标有相同符号的平台相接，理解空间重组规则。

关卡 2：只能固定两处——价值取舍
一场空间潮汐即将重组档案馆。玩家可以固定三处区域中的两处：
- 旧礼堂： 保存居民共同的仪式与历史。
- 实验工坊： 提供创造新事物的空间。
- 公共住所： 保留当下稳定的居住环境。
玩家先与居民交谈，查看每个区域的用途，再将地图钉放入两个区域。未固定的区域会进入可见的封存状态，并非被描述为“从此毫无价值”。

关卡 3：谁的历史——跨世界观察
玩家发现档案馆缺少一群外来旅人的记录，可以用有限展位展示本地传统、外来故事，或重新组织为共同展览。
这一段让“传统”与“广泛关怀”发生交叉，丰富结局依据。
实现建议： 折叠只允许发生在两三个预设位置，使用动画和场景切换实现，不开发任意折叠系统。

**世界四：无声群岛——当你的行动也影响别人**

主要张力： 刺激、愉悦、安全与广泛关怀

参考机制： “回声”

核心能力： 按键蓄力发出声波，使路径短暂显形，并激活岛上的物件。

关卡 1：听见道路——教学
轻按能力键产生短声波，长按产生远声波。平台同时通过清晰线条显形，听力不影响完成关卡。

关卡 2：沉睡的岛——价值取舍
玩家要前往另一座岛，途中有正在休息的发光生物。
- 释放强声波，可以开启宽阔的移动平台和壮观的音乐景象，但会改变生物的活动区域。
- 调整反射器，可以建立安静的通路，但需要放弃一部分可用于音乐演出的共鸣石。
- 将共鸣石留在岛上，可以维持栖息地，同时使用一条普通通路离开。
不同路线的主要操作难度接近。选择围绕玩家想实现的目标和愿意承担的影响展开。

关卡 3：为谁奏响——终章前观察
玩家使用剩余共鸣石，在个人演出、居民庆典和栖息地声景之间安排用途，回应此前在共灯之城作出的资源选择。

结果文案示例：
世界暂时称你为：织桥者。
你把城市的光留给了公共升降机，也在档案馆为陌生旅人留下了位置。面对不同的人，你多次选择让道路连接得更远。
但在庭园里，你也保护了居民熟悉的温室。对你而言，连接并不总意味着改变一切。
