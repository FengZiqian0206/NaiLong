# 螺旋漫游原型

用户目标：Three.js 网页平台跳跃游戏，圆形角色，A/D 行走、空格跳跃，世界参考手绘连续螺旋，吸附最近地面。在 FengZiqian0206/NaiLong 完成。

范围：验证移动与局部重力；不添加原策划中的叙事、敌人、复杂美术或解谜。保留 README、PROCESS 原有策划。

设计：正交二维视图，纸白背景、墨绿地形、陶红圆形主角。起点在右上，沿外圈向左进入内圈；到达中心显示完成，可立刻重来。世界地图和全景/跟随切换帮助理解空间。

核心循环：沿螺旋探索，按空格离地，观察局部重力转向并重新落地；到达中心完成。此版本为无惩罚机制原型，允许自由试验与重来。

技术：静态 ES modules + 固定版本 Three.js 0.180.0，本地 vendor 文件；固定 1/120 秒物理更新，二维圆与连续折线胶囊碰撞，最近地面决定重力。移动使用地面法线推导的局部左右，A=(-ny,nx)，D=(ny,-nx)，允许绕过末端进入底面。

更新：按用户要求移除所有多余 UI，仅保留进度、左下控制说明和 WORLD MAP。R 重来，V 切换视角，失焦暂停/聚焦恢复，不保留弹窗或暂停按钮。

已完成：物理和渲染集成，38 次连续移动跳跃、整圈正反向行走、曲面接触、末端绕行自动检查；浏览器实测 A 行走、跳跃及倒挂，视觉无控制台错误。

已完成：精简 UI 浏览器检查，真实 A 键行走到100%、R重来、D反向、空格起落、V视角切换，桌面与窄屏布局，控制台无报错。详细证据见 final-evidence.md。
